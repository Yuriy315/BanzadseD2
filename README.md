# BanzadseD2
Random Task Generator
Автор:Давид Банцадзе

Описание
Приложение для генерации случайных задач с фильтрацией по типу (учёба, спорт, работа, отдых). История задач сохраняется в файл JSON.

Использование
Запустите main.py.
Нажмите «Сгенерировать задачу» — появится случайная задача.
Используйте фильтр для выбора типа задачи.
История отображается в списке.
История сохраняется между запусками.
Технологии
Python 3.13
Tkinter (GUI).
JSON (сохранение истории).
Git (контроль версий).
Примеры использования
Генерация задачи для учёбы: выберите фильтр «учёба» и нажмите кнопку.
Просмотр истории: все сгенерированные задачи сохраняются и отображаются в списке.
